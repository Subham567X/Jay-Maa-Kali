# মায়ের আশীর্বাদ – Kali Puja Special Gift 2026
### Nakunda Kali Puja Committee Interactive Digital Gift Experience

একটি পূর্ণাঙ্গ, সুরক্ষিত, ভক্তিমূলক এবং ইন্টারেক্টিভ ডিজিটাল অ্যাপ্লিকেশন যা ২০২৬ সালের নকুন্ডা কালীপূজার স্মরণীয় উপহার হিসেবে নির্মিত। লিফলেটের QR কোড স্ক্যান করার মাধ্যমে দর্শনার্থীরা সরাসরি কোনো অ্যাপ ইনস্টল ছাড়াই যেকোনো মোবাইল ব্রাউজারে এটি উপভোগ করতে পারবেন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **স্ক্রিন ১: পুণ্য অভ্যর্থনা (Welcome Experience - `/`)**
   - মা ভবতারিণীর পুণ্য শ্রীমূর্তি ও দিব্য পরিবেশ।
   - প্রজ্বলিত প্রদীপ অ্যানিমেশন ও ভক্তিগীতি আহ্বান।
   - বোতাম: *"মায়ের আশীর্বাদ গ্রহণ করো"*।

2. **স্ক্রিন ২: মা কালীর আশীর্বাদ ভিডিও (Blessing Video - `/blessings`)**
   - মা কালীর দর্শন ও আশীর্বাদবাণী সমৃদ্ধ রেসপন্সিভ ভিডিও প্লেয়ার।
   - বাংলা সাবটাইটেল (WebVTT), ফুলস্ক্রিন ও গতি নিয়ন্ত্রক।
   - নিজস্ব ভিডিও সহজে প্রতিস্থাপনের অ্যাডমিন ব্যবস্থা।

3. **স্ক্রিন ৩: মায়ের চরণে আমার গান (Special Song - `/music`)**
   - ভক্তিগীতি অডিও প্লেয়ার, সিঙ্ক প্রোগ্রেস বার ও লিরিক্স।

4. **স্ক্রিন ৪: মায়ের মহিমা অডিওবুক (Audiobook - `/audiobook`)**
   - ৫টি বিশেষ অধ্যায়:
     1. মা কালীর আবির্ভাব
     2. মা কালীর মহিমা ও শক্তির রূপ
     3. মা কালীর ভক্তের প্রতি অপার্থিব ভালোবাসা
     4. মা কালীর আশীর্বাদ ও শরণাগতি
     5. ভক্তি, সাহস ও মানবতার শিক্ষা
   - অধ্যায় পরিবর্তন, স্পিড কন্ট্রোল (0.75x–1.5x) ও অটো-রিজিউম সুবিধা।

5. **স্ক্রিন ৫: দুই দিনের বিশেষ জ্ঞান কুইজ (Two-Day Quiz - `/quiz`)**
   - **Day 1: কালীপূজা বিশেষ কুইজ** (ঠিক ৫০টি প্রশ্ন, সর্বোচ্চ ৫০ নম্বর)
   - **Day 2: ভাইফোঁটা বিশেষ কুইজ** (ঠিক ৫০টি প্রশ্ন, সর্বোচ্চ ৫০ নম্বর)
   - মোট সম্মিলিত নম্বর: ১০০।
   - প্রতিটি প্রশ্নের ৪টি বিকল্প, এক-একটি করে প্রশ্ন প্রদর্শন, কাউন্টডাউন টাইমার, দুর্ঘটনাবশত জমাদান রোধে নিশ্চিতকরণ উইন্ডো।
   - সার্ভার-সাইড মূল্যায়ন ও ডুপ্লিকেট সাবমিশন সুরক্ষা।

6. **স্ক্রিন ৬: সংযুক্ত লিডারবোর্ড (Combined Leaderboard - `/leaderboard`)**
   - উভয় দিনের সম্মিলিত স্কোরের ভিত্তিতে র‌্যাঙ্কিং।
   - টাই-ব্রেকার: সমান স্কোরের ক্ষেত্রে স্বল্পতম সম্পন্ন সময়।

7. **স্ক্রিন ৯: একক শ্রেষ্ঠ জ্ঞানী সম্মান ২০২৬ (Winner Certificate - `/certificate`)**
   - সমগ্র প্রতিযোগিতায় শুধুমাত্র **একক বিজয়ী** পাবেন ডিজিটাল সম্মাননা শংসাপত্র: **"মায়ের আশীর্বাদ – শ্রেষ্ঠ জ্ঞানী সম্মান ২০২৬"**।
   - হাই-রেজোলিউশন ক্যানভাস, PNG এবং PDF ডাউনলোড সুবিধা।
   - পূজা কমিটির সদস্য বর্জন নীতি কঠোরভাবে কার্যকর।

8. **স্ক্রিন ১০ / সমাপন: প্রণাম ও কৃপা (Final Devotional Screen - `/pranam`)**
   - আশীর্বাদ বার্তা এবং নির্দিষ্ট কমিটি কৃতজ্ঞতা:
     **"নকুন্ডা কালীপূজা কমিটির সকল সদস্য ও সদস্যাবৃন্দ।"**

9. **পূর্ণাঙ্গ অ্যাডমিন ড্যাশবোর্ড (Admin Control Panel - `/admin`)**
   - নিরাপদ পাসওয়ার্ড ও সেশন ব্যবস্থাপনা।
   - কুইজ প্রশ্নাবলী (৫০টি প্রশ্নের ভ্যালিডেশন), টাইমার ও লকিং।
   - **কুইজ নিরাপত্তা ও ফেয়ার প্লে কন্ট্রোল (`/admin/security`):** ফুলস্ক্রিন প্রয়োগ, ট্যাব সুইচ সতর্কতা, প্রস্থান নীতি ও বাতিলকৃত প্রচেষ্টা ম্যানুয়াল রিভিউ।
   - পূজা কমিটি সদস্য ও অ্যালিয়াস ব্যবস্থাপনা (Dev Gopal Ghosh, Subham Ghorui/Ghorai, Bidyut Pal)।
   - একক বিজয়ী অনুমোদন ও সার্টিফিকেট প্রকাশ।
   - মিডিয়া ফাইল প্রতিস্থাপন ও অডিট ট্রেইল।

10. **কুইজ নিরাপত্তা, ভিডিও আশীর্বাদ ও ফেয়ার প্লে সিস্টেম (Quiz Security & Fair Play)**
   - **মা কালীর আশীর্বাদ দর্শন গেট:** কুইজ শুরুর পূর্বে অংশগ্রহণকারীকে মা কালীর পুণ্য আশীর্বাদ ভিডিও সম্পূর্ণ দেখতে হবে। ভিডিও স্কিপ করা বা সরাসরি কুইজে যাওয়া সম্পূর্ণ নিষিদ্ধ। দর্শন শেষ হলে "এবার কুইজ শুরু করো" বোতাম সক্রিয় হবে।
   - **ফোকাসড কুইজ এনভায়রনমেন্ট:** পূর্ণ পর্দা (Fullscreen) মোড সক্রিয়করণ।
   - **ট্যাব ও উইন্ডো সুইচ সনাক্তকরণ:** Page Visibility API (`visibilitychange`) এবং Focus/Blur মনিটরিংয়ের মাধ্যমে অন্য ট্যাব, উইন্ডো, সার্চ ইঞ্জিন বা বাহ্যিক অ্যাপে যাওয়া চিহ্নিত করে সতর্কতা ও লঙ্ঘন লগ তৈরি করা হয়।
   - **কঠোর প্রস্থান ও পুনঃপ্রবেশ নীতি:** কুইজ চলাকালীন ব্রাউজার ব্যাক বাটন, পৃষ্ঠা ত্যাগ বা উইন্ডো বন্ধ করলে প্রচেষ্টা তাৎক্ষণিকভাবে বাতিল (Disqualified) হয় এবং এই বাংলা বার্তা প্রদর্শিত হয়:
     > *"আপনি কুইজ থেকে বেরিয়ে গিয়েছেন। নির্ধারিত নিয়ম অনুযায়ী আপনার এই কুইজের প্রচেষ্টা বাতিল করা হয়েছে। একই কুইজে পুনরায় অংশগ্রহণ করা যাবে না।"*
   - **সার্ভার-সাইড অ্যাটেম্পট লকিং:** রিফ্রেশ বা পুনরায় ব্রাউজার খুললেও সার্ভার ডাটাবেসের কারণে প্রচেষ্টা রিসেট হয় না।

## ⚠️ গুরুত্বপূর্ণ প্রযুক্তিগত সীমাবদ্ধতা (Technical Limitations)

- একটি সাধারণ ওয়েব ব্রাউজারের প্রযুক্তিগত সীমাবদ্ধতা অনুসারে, ব্রাউজারের বাইরে অন্য কোনো ফোন, ট্যাবলেট বা ভিন্ন ডিভাইসের ব্যবহার কোনো ওয়েবসাইটের পক্ষে শারীরিকভাবে রোধ করা সম্ভব নয়।
- সিস্টেমটিতে ব্রাউজার স্তরের সর্বোত্তম ও শক্তিশালী নিরাপত্তা (Fullscreen Mode, Page Visibility API, Window Blur Tracking, Back Navigation Trap, Server Attempt Lock, Violation Audit Trail) বাস্তবায়িত হয়েছে।
- নিরীহ ব্রাউজার ইভেন্টে যেন কোনো প্রতিযোগী ভুলবশত বাতিল না হন, সেজন্য অ্যাডমিন প্যানেল থেকে সর্বোচ্চ সতর্কতা সংখ্যা (Default: 2 Warnings) এবং অ্যাডমিন ম্যানুয়াল রিভিউ ও পুনর্বহাল সুবিধা রাখা হয়েছে।

## 🛠️ প্রযুক্তিগত কাঠামো (Tech Stack)

- **ফ্রন্টএন্ড:** Next.js 14+ (App Router), React 18, TypeScript, Tailwind CSS, Lucide Icons
- **ডাটাবেস:** SQLite with Prisma ORM (সম্পূর্ণ রিলেশনাল, ACID সুরক্ষিত)
- **সার্টিফিকেট:** HTML5 2D Canvas + jsPDF
- **নিরাপত্তা:** BcryptJS পাসওয়ার্ড হ্যাশিং, JWT কুকি, সার্ভার-সাইড স্কোর ভ্যালিডেশন, ফেয়ার-প্লে ভায়োলেশন ইঞ্জিন

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল
npm install

# ২. ডাটাবেস স্কিমা আপডেট
npx prisma db push

# ৩. ১০০টি প্রশ্ন, অ্যাডমিন ও মিডিয়া ডাটা সিড করুন
npm run db:seed

# ৪. সিস্টেম ও সিকিউরিটি টেস্ট চালান
node scripts/test-security.mjs

# ৫. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে খুলুন: `http://localhost:3000`
